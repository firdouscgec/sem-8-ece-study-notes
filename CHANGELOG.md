# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-06-03

### Added
- Completed comprehensive study notes, syllabus mappings, and previous year question indices for all 4 Semester VIII ECE subjects:
  - **PE-EC801B**: Fiber Optic Communication (Units I - VI)
  - **PE-EC802B**: Industrial Automation and Control (Units I - IV)
  - **OE-EC803A**: Internet of Things (IoT) (Units I - X)
  - **OE-EC804A**: Artificial Intelligence (Units I - VIII)
- Generated active recall flashcards (`chapter_xx_qa.md` files) across all topics to enhance revision and memory retention.
- Created `quick_revision.md` sheets for high-priority definitions, formulas, and schematics.
- Implemented LaTeX compilation structure (`Latex/Main.tex`) for printing unified study companions.
- Added automation scripts in `.agents/scripts/` to convert Markdown study guides to LaTeX and generate structured flashcard documents.
- Standardized documentation layout with syllabus checklists and progress trackers.
