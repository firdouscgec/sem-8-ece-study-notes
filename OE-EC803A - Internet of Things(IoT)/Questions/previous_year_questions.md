### Group-A (Very Short Answer Type Questions)
**1. Answer any ten of the following:** `[1 x 10 = 10]`
*   **(I)** Which of the following is not an actuator in IoT?
    *   (a) Stepper motor
    *   (b) A fan
    *   (c) An LED
    *   (d) Arduino
    **Answer: (d) Arduino** 
*   **(II)** How many messages will HTTP *(written as HQTTP in original)* send in 1024?
    **Answer:** 4
*   **(III)** An HTTP response status is made up of how many digits in the status code?
    **Answer:** 3
*   **(VI)** What does IoT collect?
    *   (a) Device data
    *   (b) Machine generated data
    *   (c) Sensor data
    *   (d) Human generated data
    **Answer:** (c) Sensor data
*   **(V)** What is the role of Cloud in the smart grid architecture of IoT?
    **Answer:** The role of Cloud in the smart grid architecture of IoT is to provide a platform for storing and analyzing the data collected from the smart grid. It also provides a platform for controlling and managing the smart grid.
*   **(VI)** Which layer is used for wireless connections in IoT devices?
    *   (a) Application layer
    *   (b) Network layer
    *   (c) Data link layer
    *   (d) Transport layer
    **Answer: (c) Data link layer**
*   **(VII)** What does HTTP do?
    **Answer:** Hypertext Transfer Protocol (HTTP) is used to transfer data between a client and a server.
*   **(VIII)** Which of the following is used to capture data from the physical world in IoT devices?
    *   (a) Sensors
    *   (b) Actuators
    *   (c) Microprocessors
    *   (d) Microcontrollers
    **Answer:** (a) Sensors
*   **(IX)** How many registers are there in ARM7?
    **Answer:** 16 General Purpose Registers, 1 Program Counter, 1 Stack Pointer, 1 Link Register, 1 Program Status Register, 1 CPSR, and 1 SPSR.   
*   **(X)** Which of the following is not an IoT platform?
    *   (a) Amazon Web Services
    *   (b) Microsoft Azure
    *   (c) Salesforce
    *   (d) Flipkart
    **Answer: (d) Flipkart**
*   **(XI)** Which possibility ensures load balancing and peak leveling of energy consumption?
    **Answer:** Smart Grids
*   **(XII)** Which library is used to access I2C in Arduino IoT devices?
    **Answer:** The Wire library is used to access I2C in Arduino IoT devices.

### Group-A (Very Short Answer Type Questions)
**1. Answer any ten of the following:** `[1 x 10 = 10]`
*   **(I)** The TCP/IP model has \_\_\_\_\_\_\_ layers.
    **Answer:** 4 layers
*   **(II)** The total elements in the Open IoT Architecture is \_\_\_\_\_\_\_.
    **Answer:** 5
*   **(III)** What is the language preferred for IoT analytics?
    **Answer:** Python and R
*   **(IV)** I2C stands for \_\_\_\_\_\_\_.
    **Answer:** Inter-Integrated Circuit
*   **(V)** What is the role of Cloud in the smart grid architecture of IoT?
    **Answer:** Provides scalable data storage, processing, and analytics capabilities for smart grid data.
*   **(VI)** Which type of elements helps in streaming XMPP?
    **Answer:** MQTT elements help in streaming XMPP
*   **(VII)** In IoT, does the \_\_\_\_\_\_\_ layer help in end-to-end communication?
    **Answer:** Transport layer helps in end-to-end communication
*   **(VIII)** What is the service which permits changes to IoT services?
    **Answer:** Services API (Application Programming Interface) permits changes to IoT services
*   **(IX)** List the layers of the IoT protocol stack.
    **Answer:** 5 layers: Sensing Layer, Network Layer, Middleware Layer, Application Layer, and Business Layer
*   **(X)** How many versions of IP are there?
    **Answer:** 2 versions: IPv4 and IPv6
*   **(XI)** ITS stands for \_\_\_\_\_\_\_.
    **Answer:** Intelligent Transportation Systems
*   **(XII)** What is the purpose of WoT (Web of Things)?
    **Answer:** WoT (Web of Things) is a framework for enabling IoT devices to communicate with each other using web technologies.

### Group-A (Very Short Answer Type Questions)

*   **(I)** What is the component of an IoT system that executes a program? 
    **Answer:** Microcontroller or Microprocessor
*   **(II)** WoT (Web of Things) reduces the \_\_\_\_\_\_\_ of HTTP.
    **Answer:** Overheads
*   **(III)** What do API systems enable?
    **Answer:** API (Application Programming Interface) systems enable interaction between different software applications
*   **(IV)** What is the last step of reliable data transfer?
    **Answer:** Reliability mechanism
*   **(V)** Service is termed as \_\_\_\_\_\_\_ in SOA (Service-Oriented Architecture).
    **Answer:** Service is termed as API in SOA (Service-Oriented Architecture)
*   **(VI)** What is the format of an IP address?
    **Answer:** IP addresses are typically 32-bit numbers (IPv4) or 128-bit numbers (IPv6)
*   **(VII)** What is the full form of DHCP in IoT communication protocols?
    **Answer:** Dynamic Host Configuration Protocol (DHCP)
*   **(VIII)** The address of the original IEEE 802 MAC comes from \_\_\_\_\_\_\_.
    **Answer:** MAC (Media Access Control)
*   **(IX)** LTE stands for \_\_\_\_\_\_\_.
    **Answer:** Long-Term Evolution
*   **(X)** What is the role of the cloud in smart grid architecture?
    **Answer:** Cloud computing provides scalable data storage, processing, and analytics capabilities for smart grid data.
*   **(XI)** The standard length of a MAC address is \_\_\_\_\_\_\_.
    **Answer:** 48-bit
*   **(XII)** The Arduino IDE is written in which programming language?
    **Answer:** C++
